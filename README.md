## 🚀 Getting Started

### Installation

```bash
# Install Claude Code globally
npm install -g @anthropic-ai/claude-code

# Start Claude Code in your project
cd your-project
claude
```

### Essential Commands

| Command | Description |
|---------|-------------|
| `claude` | Start interactive REPL |
| `claude "query"` | Single-shot query |
| `claude -p "query"` | Print mode (no interactive) |
| `claude config` | Manage configuration |
| `claude mcp` | Manage MCP servers |
| `/help` | In-session help |
| `/compact` | Compress conversation context |
| `/cost` | Show token usage & costs |
| `/clear` | Clear conversation history |
| `/doctor` | Health check & diagnostics |
| `Shift+Tab` | Toggle plan mode |

### Key Features

> ![Feature](https://img.shields.io/badge/Feature-Highlights-00C853?style=flat-square)

- **Agentic Coding** — Understands your entire codebase and executes multi-step tasks
- **Tool Use** — Read/write files, run bash commands, search with grep/glob, web search
- **MCP Support** — Connect to any MCP server for extended capabilities
- **Git Integration** — Smart commits, PR creation, branch management
- **Plan Mode** — Design before you build with `Shift+Tab`
- **Sub-agents** — Spawn specialized agents for parallel tasks
- **Skills & Hooks** — Customize behavior with slash commands and event hooks
- **Multi-IDE** — VS Code, JetBrains, Neovim, Emacs integrations
- **Headless Mode** — CI/CD and automation with `-p` flag
- **Memory** — Persistent memory via `CLAUDE.md` files
